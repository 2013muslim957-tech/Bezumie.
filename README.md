# Bezumie (Безумие) — Fabric 1.20.1

Сборка: нужен JDK 17+.
    Windows:  gradlew.bat build
    Linux/Mac: ./gradlew build
Готовый файл: build/libs/Bezumie.jar  -> в папку mods (нужны Fabric Loader 0.15+ и Fabric API для 1.20.1).

Без установки Java: залей папку в репозиторий GitHub -> вкладка Actions -> "Build Bezumie.jar" -> скачай артефакт.
